# Описание класса MainActivity

## 1. Общая информация
*   **Имя класса:** `MainActivity`
*   **Тип:** Activity (Активити/Экран)
*   **Назначение:** Является главным экраном приложения. Этот класс отвечает за отображение результата поиска и запуск экрана поиска. Он служит "точкой входа", где пользователь начинает взаимодействие с программой.
*   **Взаимодействие:** Запускает `Search` Activity и ожидает от него результат (ссылку).

---

## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `tvResult` | `TextView` | Текстовое поле для вывода полученной ссылки. | В `initComponents` и в обработчике результата `arl`. |
| `bStartSearch` | `Button` | Кнопка для перехода к экрану поиска. | В `initComponents` и в `onCreate` для установки клика. |
| `context` | `Context` | Контекст приложения (ссылка на текущий объект). | В `initComponents` для создания `Intent`. |
| `arl` | `ActivityResultLauncher<Intent>` | Объект для запуска другой Активити с ожиданием результата. | В `initComponents` для регистрации и в `onCreate` для запуска. |
| `addressUri` | `Uri` | (Не используется) Потенциально для хранения адреса. | Не используется в текущей логике. |

**Пояснения:**
*   **TextView:** Элемент интерфейса, который просто показывает текст на экране.
*   **Button:** Кнопка, на которую можно нажать.
*   **Context:** Это "окружение" приложения. Оно нужно, чтобы система понимала, кто запрашивает действие (например, открытие нового окна).
*   **ActivityResultLauncher:** Современный способ Android для связи между экранами: мы отправляем запрос "сходи на тот экран и принеси данные".

---

## 3. Методы класса

### Метод: onCreate()
*   **Тип:** `protected`
*   **Возвращаемое значение:** `void` (ничего не возвращает)
*   **Параметры:** `Bundle savedInstanceState` (состояние приложения).
*   **Что делает:** Это "сердце" инициализации. Он устанавливает внешний вид экрана (`setContentView`), вызывает настройки компонентов и вешает "слушателя" на кнопку. Когда кнопка нажата, создается `Intent` (намерение) перейти в класс `Search`, и этот переход запускается через `arl.launch(go)`.
*   **Когда вызывается:** При самом старте приложения.
*   **Важно:** Нельзя забывать вызывать `super.onCreate()`, иначе приложение "упадет".

### Метод: initComponents()
*   **Тип:** `private`
*   **Возвращаемое значение:** `void`
*   **Параметры:** Нет.
*   **Что делает:** Находит элементы интерфейса в XML-файле по их ID и настраивает `arl`. Внутри `arl` прописана логика: "когда вернешься с данными, возьми из них строку 'result' и запиши её в `tvResult`".
*   **Когда вызывается:** Внутри `onCreate`.
*   **Важно:** Всегда нужно сначала вызвать `setContentView`, а потом уже искать элементы через `findViewById`.

---

## 4. Жизненный цикл (Activity)
*   **onCreate():** Вызывается первым. Здесь мы создаем всё: кнопки, тексты, связи.
*   Остальные методы (onStart, onResume и т.д.) не переопределены явно, поэтому работают в стандартном режиме Android.

---

## 5. Взаимодействие с интерфейсом (UI)
*   Используются `TextView` (`tvResult`) и `Button` (`bStartSearch`).
*   Связь через `findViewById(R.id...)`.
*   Обрабатывается событие **клик по кнопке** (`setOnClickListener`).

---

## 6. Взаимодействие с другими компонентами
*   **Intent:** Используется для перехода к `Search.class`.
*   **Передача данных:** Получает данные обратно через `Intent` в механизме `ActivityResultLauncher`. Ключ данных — `"result"`.

---

## 7. Общая логика класса
1. Приложение запускается, появляется кнопка.
2. Пользователь жмет кнопку -> открывается поиск.
3. После того как пользователь выбрал страницу в поиске и нажал "назад" (в том экране), `MainActivity` ловит ссылку.
4. Ссылка отображается на экране.

---

## 8. Упрощенное объяснение
Представьте, что `MainActivity` — это **секретарь**.
1. Секретарь сидит за столом (экран).
2. Вы даете ему команду "Найди мне информацию" (нажатие кнопки).
3. Секретарь посылает **курьера** (`Intent`) в библиотеку (`Search`).
4. Когда курьер возвращается с книгой, секретарь записывает название книги в свой блокнот (`tvResult`).

> **Совет по коду:** Переменная `addressUri` объявлена, но не используется. В хорошем коде такие "хвосты" лучше удалять.
