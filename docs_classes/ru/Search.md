# Описание класса Search

## 1. Общая информация
*   **Имя класса:** `Search`
*   **Тип:** Activity (Экран поиска/Браузер)
*   **Назначение:** Позволяет пользователю вводить поисковый запрос, искать информацию в Google через встроенный мини-браузер (`WebView`) и отправлять URL выбранного сайта обратно.
*   **Взаимодействие:** Принимает управление от `MainActivity` и возвращает результат при нажатии на специальную кнопку.

---

## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `context` | `Context` | Контекст текущего экрана. | Для инициализации компонентов. |
| `et` | `EditText` | Поле для ввода текста (запроса). | Считывается при нажатии кнопки поиска. |
| `bSearch` | `Button` | Кнопка запуска поиска. | В `onCreate` устанавливается клик. |
| `stUrl` | `String` | Хранит текст запроса пользователя. | Для формирования ссылки Google. |
| `wvs` | `WebView` | Мини-браузер внутри приложения. | Загружает страницы интернета. |
| `GOOGLE_SERACH_URL` | `String` (const) | Базовая ссылка Google. | Префикс для запроса: `https://www.google.com/search?q=` |
| `take` | `Intent` | Объект, который "привел" нас на этот экран. | В `initElements`. |

---

## 3. Методы класса

### Метод: onCreate()
*   **Тип:** `protected`
*   **Возвращаемое значение:** `void`
*   **Что делает:** Инициализирует экран. Главная логика здесь — в обработчике `bSearch.setOnClickListener`. Когда вы жмете "Поиск", программа берет текст из `et`, включает поддержку JavaScript в браузере и дает команду `wvs.loadUrl` загрузить страницу Google с вашим запросом.
*   **Когда вызывается:** При открытии экрана поиска.

### Метод: initElements()
*   **Тип:** `private`
*   **Что делает:** Простая привязка переменных к элементам дизайна (кнопки, поле ввода, веб-вью).
*   **Когда вызывается:** В начале `onCreate`.

### Метод: backWithLink()
*   **Тип:** `public`
*   **Параметры:** `View view` (нужен для связи с кнопкой в XML).
*   **Что делает:** Создает новый `Intent`, берет текущий адрес сайта из браузера (`wvs.getUrl()`), кладет его в "сумку" данных под ключом `"result"`, устанавливает статус "успешно" (`setResult`) и закрывает этот экран (`finish()`).
*   **Когда вызывается:** При нажатии на кнопку "Вернуться с ссылкой" (в дизайне).

### Внутренний класс: myWebViewClient
Это "помощник" для браузера. Без него ссылки открывались бы во внешнем Chrome, а с ним — прямо внутри вашего приложения. Он перехватывает запросы на загрузку страниц.

---

## 4. Жизненный цикл
*   **onCreate():** Точка входа, где создается интерфейс.
*   **finish():** Метод завершения. Когда вызывается `finish()`, управление возвращается в `MainActivity`.

---

## 5. Взаимодействие с интерфейсом (UI)
*   **EditText (`et`):** Место, куда ученик пишет, например, "Android Studio".
*   **WebView (`wvs`):** Самая сложная часть — компонент, умеющий показывать сайты.
*   Связь через `findViewById`.

---

## 6. Взаимодействие с другими компонентами
*   **WebView:** Взаимодействие с интернетом.
*   **setResult(111, goback):** Отправка данных обратно. Число `111` — это код результата.

---

## 7. Общая логика класса
1. Пользователь пишет слово.
2. Жмет кнопку.
3. В `WebView` открывается Google.
4. Пользователь гуляет по сайтам.
5. Находит нужный сайт, жмет "Назад с ссылкой".
6. Экран закрывается, ссылка улетает в `MainActivity`.

---

## 8. Упрощенное объяснение
Класс `Search` — это **библиотекарь с доступом в интернет**.
1. Вы приходите к нему и даете записку: "Хочу знать про котиков" (`EditText`).
2. Библиотекарь открывает свой ноутбук (`WebView`) и ищет в Google.
3. Вы выбираете страницу.
4. Библиотекарь записывает адрес этой страницы на бумажку и отдает вам, когда вы уходите (`backWithLink`).

> **Заметки для исправления:**
> 1. В `myWebViewClient` метод `shouldOverrideUrlLoading` с одним параметром устарел (Deprecated). Лучше использовать только версию с `WebResourceRequest`.
> 2. В коде есть опечатка в константе: `GOOGLE_SERACH_URL` (пропущена 'a'). Стоит исправить на `GOOGLE_SEARCH_URL`.
