🎯 Цель проекта
•	**Какую задачу решает приложение:** Позволяет пользователю выполнять поисковые запросы в Google напрямую через встроенный WebView и возвращать URL выбранной страницы в главное окно приложения.
•	**Почему эта задача важна:** Демонстрирует взаимодействие между активити с использованием `ActivityResultLauncher`, работу с `WebView` и передачу данных через `Intent`.
•	**Целевая аудитория:** Разработчики, изучающие основы Android-разработки.
________________________________________
📌 Требования к приложению
**Функциональные требования**
•	Ввод поискового запроса.
•	Отображение результатов поиска Google в приложении.
•	Возможность вернуться на главный экран с URL-адресом текущей страницы.
**Нефункциональные требования**
•	**Производительность:** Быстрая загрузка веб-страниц.
•	**Удобство использования:** Минималистичный интерфейс.
•	**Надёжность:** Стабильная работа при переходах между окнами.
________________________________________
🧠 Общая архитектура
•	**Выбранный подход:** MVC (Model-View-Controller)
•	**Почему выбран именно он:** Проект имеет небольшой масштаб, поэтому стандартная структура Android Activity полностью удовлетворяет потребностям без лишнего усложнения.
•	**Основные компоненты системы:**
    - `MainActivity`: Отображает результат и запускает поиск.
    - `Search`: Обрабатывает ввод и отображает WebView.

🧩 Подробное описание классов
📌 Класс: MainActivity
**Роль:** Точка входа в приложение.
**Ответственность:** Отображение полученной ссылки от поисковика.
**Основные методы:** 
- `onCreate()` — установка макета и слушателей.
- `initComponents()` — инициализация UI и `ActivityResultLauncher`.
**Взаимодействие с другими классами:** Запускает `Search` через `Intent`.
________________________________________
📌 Класс: Search
**Роль:** Экран поиска.
**Ответственность:** Ввод запроса, отображение WebView, возврат ссылки.
**Основные методы:**
- `initElements()` — инициализация компонентов.
- `backWithLink()` — возврат текущего URL в `MainActivity`.
- `myWebViewClient` — внутренний класс для управления загрузкой страниц внутри WebView.
________________________________________
🔄 Диаграмма работы приложения
**Сценарий:**
1. Пользователь нажимает "Start Search" в `MainActivity`.
2. Вводит текст в `Search` и нажимает кнопку поиска.
3. Просматривает результаты в `WebView`.
4. Нажимает кнопку возврата, и URL страницы отображается в `MainActivity`.
