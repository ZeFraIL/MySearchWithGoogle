🎯 هدف المشروع
•	**ما هي المشكلة التي يحلها التطبيق:** يتيح للمستخدم إجراء عمليات بحث في Google مباشرة من خلال WebView مدمج وإعادة عنوان URL للصفحة المختارة إلى النافذة الرئيسية للتطبيق.
•	**لماذا هذه المهمة مهمة:** توضح التفاعل بين الأنشطة (Activities) باستخدام `ActivityResultLauncher` والعمل مع `WebView` ونقل البيانات عبر `Intent`.
•	**الجمهور المستهدف:** المطورون الذين يتعلمون أساسيات تطوير أندرويد.
________________________________________
📌 متطلبات التطبيق
**المتطلبات الوظيفية**
•	إدخال استعلام البحث.
•	عرض نتائج بحث Google داخل التطبيق.
•	القدرة على العودة إلى الشاشة الرئيسية مع عنوان URL للصفحة الحالية.
**المتطلبات غير الوظيفية**
•	**الأداء:** تحميل سريع لصفحات الويب.
•	**سهولة الاستخدام:** واجهة بسيطة.
•	**الموثوقية:** عمل مستقر أثناء الانتقال بين النوافذ.
________________________________________
🧠 المعمارية العامة
•	**النهج المختار:** MVC (Model-View-Controller)
•	**لماذا تم اختياره:** المشروع صغير الحجم، لذا فإن هيكل الـ Activity القياسي في أندرويد يلبي الاحتياجات تمامًا دون تعقيد غير ضروري.
•	**المكونات الأساسية للنظام:**
    - `MainActivity`: يعرض النتيجة ويطلق عملية البحث.
    - `Search`: يعالج الإدخال ويعرض الـ WebView.

🧩 وصف تفصيلي للفئات
📌 الفئة: MainActivity
**الدور:** نقطة الدخول للتطبيق.
**المسؤولية:** عرض الرابط المستلم من محرك البحث.
**الأساليب الرئيسية:** 
- `onCreate()` — إعداد التخطيط والمستمعين.
- `initComponents()` — تهيئة واجهة المستخدم و `ActivityResultLauncher`.
**التفاعل مع الفئات الأخرى:** يطلق `Search` عبر `Intent`.
________________________________________
📌 الفئة: Search
**الدور:** شاشة البحث.
**المسؤولية:** إدخال الاستعلام، عرض WebView، وإعادة الرابط.
**الأساليب الرئيسية:**
- `initElements()` — تهيئة المكونات.
- `backWithLink()` — يعيد عنوان URL الحالي إلى `MainActivity`.
- `myWebViewClient` — فئة داخلية لإدارة تحميل الصفحات داخل WebView.
________________________________________
🔄 مخطط سير عمل التطبيق
**السيناريو:**
1. ينقر المستخدم على "Start Search" في `MainActivity`.
2. يدخل النص في `Search` وينقر على زر البحث.
3. يتصفح النتائج في `WebView`.
4. ينقر على زر العودة، ويتم عرض عنوان URL للصفحة في `MainActivity`.
